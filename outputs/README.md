# Outputs

This directory contains the tables, figures and execution logs generated by the Stata analysis.

The project is at the data-acquisition and implementation stage. No regression tables or figures are committed as empirical findings until the source files have been downloaded, the merged panel has been validated, and the analysis has been executed in Stata.

Expected outputs:

- tables/sample_coverage.txt
- tables/descriptive_statistics.txt
- tables/correlation_matrix.txt
- tables/baseline_models.txt
- tables/asymmetric_model.txt
- tables/robustness_models.txt
- figures/credit_gap_by_country.png
- figures/credit_gap_gdp_scatter.png
- logs/analysis.log

These files are descriptive and inferential outputs from the specified observational design. They must not be described as causal estimates.
