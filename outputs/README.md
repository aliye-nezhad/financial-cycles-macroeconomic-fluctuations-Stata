# Outputs

This directory contains the tables, figures and execution logs generated by the Stata analysis.

Source data have been downloaded and the preliminary sample audit is complete. No regression tables or figures are committed as empirical findings until the Stata analysis has been executed and its sample counts have been reconciled with the audit.
